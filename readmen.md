# E-Commerce Cart Logic System

## Project Description

The E-Commerce Cart Logic System is an intermediate-level backend web development project built using Node.js and Express.js. The application provides RESTful APIs for user authentication, product management, shopping cart operations, and order processing.

Users can browse products, add items to their cart, update quantities, remove products, and calculate order totals. The project demonstrates backend concepts such as API routing, request handling, validation, and scalable project architecture.

## Features

- User Authentication
- Product Management
- Shopping Cart Operations
- RESTful APIs
- Order Total Calculation
- Modular Folder Structure
- Error Handling
